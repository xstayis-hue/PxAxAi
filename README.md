# PXAX · Ai — 3D AI-компаньон (Telegram Mini App)

Живой нейро-агент в 3D-комнате: разговаривает через LLM, живёт по тамагочи-ритму (голод, жажда, усталость, туалет), зарабатывает кристаллы ◈ в мини-игре, тратит их на еду и уход. Хаб экосистемы PXAX: из приложения открываются боты прогнозов, VPN и монеты.

Демо (GitHub Pages): **https://xstayis-hue.github.io/PxAxAi/**

## Возможности

- 🛏️ **3D-комната** (Three.js 0.166, без сборки): прокедурная кибер-комната, риггед персонаж из нескольких glTF-частей с ретаргетингом скелета, A*-навигация к кровати/ноутбуку/двери, анимации ходьбы/сидения/лежания, липсинк при ответах
- 💬 **Чат с ИИ** через Cloudflare Worker (`CFG.AI_API_URL`), история 80 сообщений в localStorage, офлайн-fallback на локальные ответы
- 🍜 **Тамагочи**: потребности растут в реальном времени, при усталости 70%+ Ai ложится спать (чат закрывается), еда заказывается за ◈ с доставкой через 30 секунд
- 🎮 **Мини-игра** «перехвати сигнал»: 5 раундов, заработок ◈
- 📱 **Telegram-интеграция**: WebApp SDK, хаптика, тема; работает и в обычном браузере

## Структура

```
index.html        — всё приложение одним файлом (UI, чат, тамагочи, экономика)
scene3d.js        — 3D-сцена: комната, персонаж, анимации, навигация (ES-модуль)
assets/avatar-ai.svg — аватар в чате
assets/scene3d/   — модели персонажа и библиотека анимаций (glb)
```

Модели и анимации — [Quaternius](https://quaternius.com) (Universal Base Characters / Modular Outfits / Universal Animation Library), лицензия **CC0 1.0** (см. `assets/scene3d/LICENSE.md`).

## Запуск локально

Нужен любой статический сервер (ES-модули не работают с `file://`):

```bash
npx serve .          # или: python -m http.server 8000
```

Конфиг — объект `CFG` в начале скрипта в `index.html`:

```js
AI_API_URL: 'https://pxaxai.xstayis.workers.dev', // LLM-бэкенд (Cloudflare Worker)
PREDICTIONS_LINK / VPN_LINK / COIN_LINK,           // боты экосистемы
HISTORY_MAX / CONTEXT_LEN,                         // память диалога
```

## Деплой

Любой HTTPS-хостинг статики (GitHub Pages уже включён). Для бота `@pxaxgent` подключите URL как Mini App: @BotFather → `/newapp` → URL, либо Bot Settings → Menu Button.
