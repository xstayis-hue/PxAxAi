# PXAX · Nova — 3D AI-компаньон (Telegram Mini App)

Живой нейро-агент в 3D-комнате: разговаривает через LLM, живёт по тамагочи-ритму (голод, жажда, усталость, туалет), зарабатывает кристаллы ◈ в мини-играх, тратит их на еду и уход. Хаб экосистемы PXAX: из приложения открываются боты прогнозов, VPN и монеты.

**Демо (GitHub Pages):** https://xstayis-hue.github.io/PxAxAi/
**Telegram-бот для привязки:** `@PxAxAi_bot`

## Что умеет (v0.5 «живой компаньон»)

- 🫀 **Жизнь на сервере.** Потребности тикают в Cloudflare Worker по реальному времени, даже когда приложение закрыто: `sync`/`life` догоняют голод, жажду, усталость и туалет, сервер сам запускает сон (усталость ≥ 70%) и отлучку. Приложение теперь лишь отображает то, что сервер уже посчитал.
- 🧠 **Память вместо 12 строк.** Кроме фактов Nova копит **эпизоды диалога** и подтягивает в промпт только релевантные к текущей теме («в вашей истории всплывает…»), с давностью («вчера», «3 дн. назад»).
- 💬 **Своя инициатива.** Раз в несколько часов cron генерирует «внутренний монолог» Nova и она **пишет первой**: сообщение либо уходит пушем в Telegram, либо ждёт в приложении и показывается при открытии чата.
- 🎙️ **Голос — качественный или никакой.** Выбирается лучший русский женский голос (Google/Светлана/Ирина…); если хорошего нет — озвучка полностью отключается, вместо роботизированного акцента.
- 🏠 **Онбординг первого запуска.** Короткое знакомство, выбор имени компаньона и объяснение правил — вместо пустой комнаты.
- 🔥 **Ритуал возвращения.** За возвращение после паузы — кристаллы ◈ (6–30 в зависимости от времени), вехи стрика 3/7/14/30 дней с наградой, приветствие с «сколько не виделись».
- ☁️ **Облако работает всегда.** Хранилище — KV (`MEMORY`), D1 подключается опционально для строгой атомарности. `sync`/`life`/промокоды не ломаются без D1.
- 🔐 **Чужой save недостижим.** `id` из неподписанного `X-Telegram-Init-Data` больше никогда не становится ключом пользователя: подпись валидна → `tg:<id>`, иначе — отдельный ip-бакет. Промокод одноразов для каждой идентичности.
- 🛡️ **Античит.** Лимит частоты push (1/3 c), суточные потолки прироста ◈ и XP, плюс клампы за один push.
- 📊 **Наблюдаемость.** Счётчики ошибок в KV: `GET /?stats=1` показывает, что падало за день.
- 🛏️ **3D-комната** (Three.js 0.166, без сборки): процедурная кибер-комната, риггед-персонаж с ретаргетингом скелета, A*-навигация, анимации ходьбы/сидения/лежания, липсинк.
- 📸 **Фото-студия:** снимок 3D-комнаты через WebGL `toDataURL` → «Поделиться / Скачать».
- 💬 **State-aware чат** через Worker: **SSE-стриминг** токенов, кнопка Stop, автооткат на JSON.
- 🗣️ **Команды на естественном языке:** «иди к ноутбуку», «ложись спать», «чем занята?» — офлайн-парсер + JSON-action от LLM.
- 🍜 **Тамагочи:** потребности копятся медленно; еда за ◈ с доставкой за 30 секунд; редкие события и LLM-сны из событий дня.
- 🎟️ **Промокоды** экосистемы (PXAX-BETPAY / PXAX-PREDICT / PXAX-VPH / PXAX-NOW) → ◈.
- 🔔 **Пуш-напоминания** в Telegram по deep-link `?start=px_<userId>`.
- 🎯 **Дейли-квесты и стрик** + 🎮 **мини-игры** с кулдауном 30 минут.
- 📱 **Telegram-интеграция** (WebApp SDK, хаптика, тема) и ♿ **PWA + accessibility**.

## Структура

```
index.html           — приложение одним файлом (UI, чат, тамагочи, экономика)
scene3d.js           — 3D-сцена: комната, персонаж, анимации, навигация (ES-модуль)
js/
  api.js             — сетевой слой: JSON + SSE-стрим + AbortController + initData-заголовок
  agent-actions.js   — парсер команд на естественном языке → действия комнаты
  perf.js            — reduced-motion, пауза при скрытой вкладке
  quests.js          — дейли-квесты, стрик и вехи
  games.js           — canvas-мини-игры (Neon Reflex, Data Run)
  life.js            — живой компаньон: онбординг, ритуал возвращения, голос, инициатива
assets/
  avatar-nova.svg      — аватар в чате
  scene3d/           — модели персонажа и библиотека анимаций (glb)
worker/
  index.js           — Cloudflare Worker: серверная жизнь, память+эпизоды, инициатива, LLM, SSE
  wrangler.toml      — конфиг деплоя (KV MEMORY + опциональный D1 + cron)
  schema.sql         — схема D1 (нужна только при подключении D1)
  test/worker.test.mjs — тесты воркера (node worker/test/worker.test.mjs)
manifest.webmanifest — PWA-манифест
sw.js                — service worker (статика в кэш, API в сеть)
```

Модели и анимации — [Quaternius](https://quaternius.com) (Universal Base Characters / Modular Outfits / Universal Animation Library), лицензия **CC0 1.0** (см. `assets/scene3d/LICENSE.md`).

## Запуск локально

Нужен любой статический сервер (ES-модули не работают с `file://`):

```bash
npx serve .          # или: python -m http.server 8000
```

Открой `http://localhost:8000`. Конфиг — объект `CFG` в начале скрипта в `index.html`:

```js
AI_API_URL: 'https://pxaxai.xstayis.workers.dev', // LLM-бэкенд (Cloudflare Worker)
PREDICTIONS_LINK / VPN_LINK / COIN_LINK,           // боты экосистемы
HISTORY_MAX / CONTEXT_LEN,                         // память диалога (localStorage)
```

## Воркер (LLM-бэкенд + жизнь)

Код — в [`worker/`](worker/). Ключевое:

- принимает `{ message, history, state, tzShift, availableActions, links }`;
- если есть `Accept: text/event-stream` — стримит токены (SSE);
- маршрутизация по `action`:
  - `sync` (`op: push|pull`) — кросс-девайс состояние; сервер **догоняет время** (`advanceNeeds`) и сам запускает сон/отлучку;
  - `life` — «что случилось, пока меня не было»: время отсутствия, настроение, эпизоды, отложенное сообщение от Nova;
  - `code` — промокоды (одноразовые на идентичность);
  - `dream` — LLM-сценка-сон из событий дня;
- хранилище: KV `MEMORY` (ключи `save:`, `mem:`, `push:`, `code:`, `pend:`, `rl:`); D1 `DB` подключается опционально;
- память = факты + **эпизоды** диалога с релевантным recall в промпт (пересечение слов + свежесть);
- `X-Telegram-Init-Data` проверяется по HMAC-SHA256 (constant-time, свежесть ≤ 24ч); неподписанный `id` **никогда** не становится ключом — такие запросы идут в отдельный ip-бакет;
- cron `0 7 * * *` — утренний дайджест; cron `0 */3 * * *` — жизнь: догоняет потребности и генерирует инициативу Nova (пуш в Telegram и/или отложенное сообщение);
- античит: лимит частоты push, суточные потолки прироста ◈/XP, клампы за один push;
- наблюдаемость: `GET /?stats=1` — счётчики ошибок за день;
- обратно совместим со старым клиентом (`{ reply, model }`).

### Деплой воркера

```bash
cd worker
npx wrangler login
npx wrangler deploy
# опционально: TELEGRAM_BOT_TOKEN, чтобы включить проверку подписи, пуши и инициативу
npx wrangler secret put TELEGRAM_BOT_TOKEN
```

KV `MEMORY` уже настроен в `wrangler.toml`. D1 — опционален (даёт строгую атомарность промокодов и SQL по всем юзерам):

```bash
npx wrangler d1 create pxaxai                 # появится database_id
# раскомментируй [[d1_databases]] в wrangler.toml и вставь database_id
npx wrangler d1 execute pxaxai --remote --file=schema.sql
npx wrangler deploy
```
